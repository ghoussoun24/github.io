Projet phare — stage PFE

LEONI RH — de la candidature au recrutement, automatisé de bout en bout

Plateforme intelligente de gestion des stages et du recrutement développée pour LEONI Tunisia (Monastir). Objectif : remplacer un processus RH manuel — CV lus un par un, saisis dans Excel — par un pipeline automatisé de bout en bout, du dépôt de CV jusqu'au recrutement basé sur l'historique des stagiaires.

01

Dépôt CV

Le candidat dépose son CV (PDF, image, Word) depuis une interface React.

React 18
02

Orchestration

Un workflow n8n déclenché par webhook télécharge, extrait et prépare le texte du CV.

n8n
03

Analyse IA

Groq (LLaMA 3) extrait compétences, projets, certifications puis calcule un score de compatibilité /100.

Groq API
04

Conteneurisation

Backend Django, frontend React et n8n conteneurisés et testés via GitHub Actions + SonarCloud.

Docker · CI/CD
05

Déploiement

Orchestration Kubernetes avec autoscaling, Ingress et supervision Prometheus / Grafana.

Kubernetes

⚙ Ce que j'ai fait — DevOps
  • Conteneurisation des 3 services (Django, React, n8n) avec Dockerfiles optimisés + Docker Compose
  • Pipeline CI/CD GitHub Actions : tests unitaires, couverture, build & push Docker Hub, release automatique
  • Analyse qualité continue avec SonarCloud — 249 tests, 81,6 % de couverture, Quality Gate A
  • Cluster Kubernetes (namespace dédié) : Deployments, Services NodePort, Ingress Nginx, PVC pour les CV et les workflows
  • Autoscaling HPA sur le backend (2→5 pods) déclenché et validé sous charge réelle
  • Tests de charge avec Locust — 500 utilisateurs simultanés, 0 % d'échec, autoscaling confirmé (CPU 298 % → scale 2→4 pods)
  • Supervision Prometheus + Grafana + cAdvisor + Node Exporter, dashboards latence & trafic HTTP
✦ Ce que j'ai fait — IA
  • Intégration de l'API Groq (modèles LLaMA) pour l'extraction structurée des CV : compétences, projets, stages, certifications
  • Moteur de scoring : compatibilité candidat / sujet de stage sur 100 points (niveau, spécialité, compétences, projets)
  • Génération automatique de points forts, points faibles et recommandation RH pour chaque candidature
  • Module de matching intelligent recrutement : pré-filtrage Python + affinage sémantique Groq pour comparer d'anciens stagiaires à une offre d'emploi
  • Gestion des cas limites : CV scannés, images, Word — fallback OCR côté backend
◆ Ce que j'ai fait — n8n
  • Conception du workflow d'orchestration complet : webhook → extraction → appel Groq → scoring → mise à jour Django
  • Simplification du workflow de 23 à ~13 nœuds suite à une revue technique, sans perte de fonctionnalité
  • Authentification hybride service-à-service (clé API statique en environnement Kubernetes, JWT en local)
  • Deux environnements de workflow maintenus en parallèle (local et cluster) pour garantir la continuité des tests
